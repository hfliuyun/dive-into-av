## 理论讲解

### 核心概念1：为什么可以压缩？

视频压缩的可行性基于两个关键原理：

#### 1.1 空间冗余（帧内压缩）

相邻像素之间通常非常相似：

```
原始图像（8x8 块）：
120 122 125 128 130 132 135 138
121 123 126 129 131 133 136 139
...
```

这些相似的值可以用更少的数据表示。

#### 1.2 时间冗余（帧间压缩）

视频中相邻帧通常非常相似：

```
帧 1：[120, 122, 125, ...]
帧 2：[121, 123, 126, ...]  ← 只差 1
帧 3：[122, 124, 127, ...]  ← 只差 2
```

只需要存储差异，而不是完整帧。

---

### 核心概念2：DCT（离散余弦变换）

**DCT** 是将空间域信号转换为频率域信号的数学工具。

#### 2.1 什么是 DCT？

DCT 将一组像素值转换为一组频率系数：

```
空间域（像素） → DCT → 频率域（系数）
[120, 122, 125, ...] → DCT → [1000, 50, 10, ...]
```

- **低频系数**：代表图像的平滑区域（大部分能量）
- **高频系数**：代表图像的细节和边缘（少量能量）

#### 2.2 8x8 DCT 公式

对于 8x8 的像素块，DCT 公式为：

```
F(u,v) = C(u) × C(v) × Σ Σ f(x,y) × cos[(2x+1)uπ/16] × cos[(2y+1)vπ/16]
```

其中：
- `f(x,y)` 是像素值
- `F(u,v)` 是频率系数
- `C(0) = √(1/8)`，`C(k) = √(2/8)` for k > 0

#### 2.3 DCT 的直观理解

**示例**：8x8 像素块的 DCT

```
原始像素块（空间域）：
120 122 125 128 130 132 135 138
121 123 126 129 131 133 136 139
...

DCT 系数（频率域）：
1000   50   10    5    2    1    0    0
  50   20    5    2    1    0    0    0
  10    5    2    1    0    0    0    0
...
```

- 左上角（低频）：系数大，代表图像的主要能量
- 右下角（高频）：系数小，代表图像的细节

---

### 核心概念3：量化

**量化** 是将 DCT 系数除以量化矩阵并取整的过程。

#### 3.1 量化公式

```
量化系数 = round(DCT系数 / 量化步长)
```

**示例**：
- DCT 系数：1000
- 量化步长：10
- 量化系数：round(1000 / 10) = 100

#### 3.2 量化矩阵

JPEG 标准使用亮度量化矩阵（教学示例）：

```
JPEG 标准亮度量化矩阵（8x8）：
16  11  10  16  24  40  51  61
12  12  14  19  26  58  60  55
14  13  16  24  40  57  69  56
14  17  22  29  51  87  80  62
18  22  37  56  68 109 103  77
24  35  55  64  81 104 113  92
49  64  78  87 103 121 120 101
72  92  95  98 112 100 103  99
```

- 左上角（低频）：量化步长小，保留更多细节
- 右下角（高频）：量化步长大，丢弃更多细节

#### 3.3 量化对画质的影响

**量化参数（QP）** 控制压缩率和画质。H.264 标准中，QP 每增加 6，量化步长翻倍：

| QP | 量化步长 | 压缩率 | 画质 |
|----|----------|--------|------|
| 0 | 0.625 | 低 | 最高 |
| 23 | 10 | 中 | 中等 |
| 51 | 224 | 高 | 最低 |

**QP 越大**：量化步长越大，压缩率越高，画质越差。

---

### 核心概念4：熵编码

**熵编码** 是将量化后的系数转换为二进制码流的过程。

#### 4.1 常见熵编码方法

| 方法 | 特点 | 应用 |
|------|------|------|
| 霍夫曼编码 | 变长编码，高频符号用短码 | JPEG、H.264 |
| 算术编码 | 更高效的变长编码 | H.265、AV1 |
| CAVLC | 上下文自适应变长编码 | H.264 基线配置 |
| CABAC | 上下文自适应二进制算术编码 | H.264 主配置 |

#### 4.2 熵编码的原理

**原理**：高频出现的符号用短码，低频出现的符号用长码。

**示例**：
- 符号 A 出现频率 50% → 编码为 0
- 符号 B 出现频率 25% → 编码为 10
- 符号 C 出现频率 25% → 编码为 11

---

### 核心概念5：压缩失真

压缩失真是由量化引起的：

#### 5.1 失真类型

| 失真类型 | 表现 | 原因 |
|----------|------|------|
| 块效应 | 图像出现方块边界 | 量化步长过大 |
| 模糊 | 图像细节丢失 | 高频系数被丢弃 |
| 振铃效应 | 边缘出现波纹 | 高频系数截断 |

#### 5.2 失真与码率的关系

```
码率高 → QP 小 → 量化步长小 → 失真小 → 画质好
码率低 → QP 大 → 量化步长大 → 失真大 → 画质差
```

---

## 关键点总结

| 要点 | 一句话总结 |
|------|-----------|
| **压缩基于冗余** | 空间冗余（帧内）和时间冗余（帧间）使压缩成为可能 |
| **DCT 转换频率** | DCT 将空间域转换为频率域，低频系数代表主要能量 |
| **量化丢弃细节** | 量化将 DCT 系数除以步长并取整，丢弃高频细节 |
| **熵编码压缩数据** | 熵编码用短码表示高频符号，进一步压缩数据 |
| **QP 控制画质** | QP 越大，量化越狠，压缩率越高，画质越差 |

## 核心代码实验

### 实验1：手写 8x8 DCT

**目标**：理解 DCT 变换的原理

**代码实现：**
```python
import numpy as np

def dct_1d(signal):
    """一维 DCT 变换"""
    N = len(signal)
    result = np.zeros(N)
    
    for k in range(N):
        sum_val = 0
        for n in range(N):
            sum_val += signal[n] * np.cos(np.pi * (2 * n + 1) * k / (2 * N))
        
        if k == 0:
            result[k] = sum_val * np.sqrt(1 / N)
        else:
            result[k] = sum_val * np.sqrt(2 / N)
    
    return result

def dct_2d(block):
    """二维 DCT 变换（先对行做 DCT，再对列做 DCT）"""
    rows, cols = block.shape
    
    # 对每一行做 DCT
    temp = np.zeros_like(block, dtype=float)
    for i in range(rows):
        temp[i, :] = dct_1d(block[i, :].astype(float))
    
    # 对每一列做 DCT
    result = np.zeros_like(block, dtype=float)
    for j in range(cols):
        result[:, j] = dct_1d(temp[:, j])
    
    return result

# 测试 DCT
print("=" * 50)
print("DCT 变换实验")
print("=" * 50)

# 创建测试块
block = np.array([
    [120, 122, 125, 128, 130, 132, 135, 138],
    [121, 123, 126, 129, 131, 133, 136, 139],
    [122, 124, 127, 130, 132, 134, 137, 140],
    [123, 125, 128, 131, 133, 135, 138, 141],
    [124, 126, 129, 132, 134, 136, 139, 142],
    [125, 127, 130, 133, 135, 137, 140, 143],
    [126, 128, 131, 134, 136, 138, 141, 144],
    [127, 129, 132, 135, 137, 139, 142, 145]
], dtype=np.uint8)

print(f"\n原始像素块 (8x8):")
print(block)

# 执行 DCT
dct_coeffs = dct_2d(block)

print(f"\nDCT 系数 (8x8):")
print(np.round(dct_coeffs, 1))
```

**代码解析：**
- `dct_1d`：一维 DCT 变换
- `dct_2d`：二维 DCT 变换（先对行做 DCT，再对列做 DCT）
- DCT 将空间域转换为频率域

### 实验2：量化与反量化

**目标**：理解量化的作用和对画质的影响

**代码实现：**
```python
def quantize(dct_coeffs, qp=23):
    """量化 DCT 系数"""
    # 标准量化矩阵
    q_matrix = np.array([
        [16, 11, 10, 16, 24, 40, 51, 61],
        [12, 12, 14, 19, 26, 58, 60, 55],
        [14, 13, 16, 24, 40, 57, 69, 56],
        [14, 17, 22, 29, 51, 87, 80, 62],
        [18, 22, 37, 56, 68, 109, 103, 77],
        [24, 35, 55, 64, 81, 104, 113, 92],
        [49, 64, 78, 87, 103, 121, 120, 101],
        [72, 92, 95, 98, 112, 100, 103, 99]
    ])
    
    # 根据 QP 调整量化步长
    if qp < 30:
        scale = 1
    elif qp < 40:
        scale = 2
    else:
        scale = 4
    
    q_step = q_matrix * scale
    
    # 量化
    quantized = np.round(dct_coeffs / q_step).astype(int)
    
    return quantized, q_step

def dequantize(quantized, q_step):
    """反量化"""
    return quantized * q_step

# 测试量化
print("=" * 50)
print("量化实验")
print("=" * 50)

# 使用不同的 QP 进行量化
for qp in [0, 23, 40, 51]:
    quantized, q_step = quantize(dct_coeffs, qp)
    dequantized = dequantize(quantized, q_step)
    
    print(f"\nQP = {qp}:")
    print(f"  量化后非零系数: {np.count_nonzero(quantized)}")
    print(f"  量化矩阵:\n{q_step}")
```

**代码解析：**
- `quantize`：将 DCT 系数除以量化步长并取整
- `dequantize`：将量化系数乘以量化步长恢复
- QP 控制量化步长，QP 越大，量化越狠

### 实验3：观察压缩前后的图像变化

**目标**：理解压缩失真的原因

**代码实现：**
```python
import matplotlib.pyplot as plt

def idct_1d(signal):
    """一维逆 DCT 变换"""
    N = len(signal)
    result = np.zeros(N)
    
    for n in range(N):
        sum_val = 0
        for k in range(N):
            if k == 0:
                sum_val += signal[k] * np.sqrt(1 / N)
            else:
                sum_val += signal[k] * np.sqrt(2 / N) * np.cos(np.pi * (2 * n + 1) * k / (2 * N))
        
        result[n] = sum_val
    
    return result

def idct_2d(dct_coeffs):
    """二维逆 DCT 变换"""
    rows, cols = dct_coeffs.shape
    
    # 对每一列做逆 DCT
    temp = np.zeros_like(dct_coeffs, dtype=float)
    for j in range(cols):
        temp[:, j] = idct_1d(dct_coeffs[:, j])
    
    # 对每一行做逆 DCT
    result = np.zeros_like(dct_coeffs, dtype=float)
    for i in range(rows):
        result[i, :] = idct_1d(temp[i, :])
    
    return result

# 可视化对比
fig, axes = plt.subplots(2, 3, figsize=(12, 8))

# 原始图像
axes[0, 0].imshow(block, cmap='gray', vmin=0, vmax=255)
axes[0, 0].set_title('Original')
axes[0, 0].axis('off')

# 不同 QP 的压缩结果
for idx, qp in enumerate([0, 23, 40, 51]):
    row = idx // 2
    col = idx % 2 + 1
    
    quantized, q_step = quantize(dct_coeffs, qp)
    dequantized = dequantize(quantized, q_step)
    reconstructed = idct_2d(dequantized)
    
    axes[row, col].imshow(np.clip(reconstructed, 0, 255).astype(np.uint8), cmap='gray', vmin=0, vmax=255)
    axes[row, col].set_title(f'QP={qp}')
    axes[row, col].axis('off')

plt.tight_layout()
plt.savefig('dct_comparison.png', dpi=150)
plt.show()

print("对比图已保存到 dct_comparison.png")
```

**代码解析：**
- `idct_1d`：一维逆 DCT 变换
- `idct_2d`：二维逆 DCT 变换
- 可视化不同 QP 下的压缩效果

## 常见错误与排查

### 错误1：DCT 系数全为 0

**原因**：输入像素块全为相同值。

**排查**：
- 检查输入像素块是否有变化
- 使用有梯度的测试块

### 错误2：量化后非零系数太多

**原因**：QP 太小，量化步长太小。

**排查**：
- 增大 QP
- 检查量化矩阵

### 错误3：反量化后图像失真严重

**原因**：QP 太大，量化步长太大。

**排查**：
- 减小 QP
- 检查量化矩阵

## 面试延伸题

### Q1：DCT 变换的作用是什么？

**答题要点**：
1. DCT 将空间域转换为频率域
2. 低频系数代表图像的主要能量，高频系数代表细节
3. 量化可以丢弃高频系数，实现压缩

### Q2：量化参数（QP）如何影响画质？

**答题要点**：
1. QP 越大，量化步长越大，压缩率越高
2. QP 越大，高频细节丢失越多，画质越差
3. QP 是码率控制的核心参数

### Q3：为什么视频可以压缩？

**答题要点**：
1. 空间冗余：相邻像素相似
2. 时间冗余：相邻帧相似
3. 视觉冗余：人眼对高频细节不敏感
