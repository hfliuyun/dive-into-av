# 《动手学音视频开发》

## 课程简介
本课程通过"理论+可运行代码+实验"的方式系统学习音视频技术，打破传统学习曲线，从基础概念到工程实战。

## 课程特色
- 🧪 **实验驱动**：每节课包含理论讲解和动手实验
- 📊 **可视化反馈**：前期使用Python+Jupyter进行数据可视化
- 🔧 **工程落地**：后期过渡到C+++FFmpeg API实现工业级代码
- 📈 **渐进式学习**：从单帧处理到完整播放器，再到网络流媒体

## 目录结构
```
dive_into_media/
├── README.md              # 项目总览
├── requirements.txt       # Python依赖
├── docs/                  # 课程讲义
│   └── module1_basics/   # 模块一：基础概念
├── notebooks/             # Jupyter实验笔记本
│   └── module1/
├── src/                   # C++工程代码（后续模块）
├── assets/                # 测试素材（自动生成）
└── output/                # 实验输出文件
```

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动Jupyter
```bash
jupyter notebook notebooks/
```

### 3. 开始学习
打开 `notebooks/module1/01_pixel_exploration.ipynb` 开始第一节课

## 课程大纲

### 模块一：音视频基础概念与数据可视化
- 第1节：数字图像基础 ⭐ 当前课程
- 第2节：视频的色彩空间
- 第3节：数字音频基础
- 第4节：音视频容器格式与编解码
- 第5节：帧率、码率与时间戳

### 模块二：音视频编解码核心原理
- 第6节：视频编码原理（DCT + 量化）
- 第7节：H.264关键帧与参考帧
- 第8节：音频编码原理（AAC/MP3）
- 第9节：FFmpeg解码器API入门
- 第10节：FFmpeg内存模型与引用计数
- 第11节：FFmpeg编码器API入门

### 模块三：音视频解封装、封装与处理管道
- 第12节：解封装与封装API详解
- 第13节：解码管道构建
- 第14节：图像滤镜与转码（libavfilter + libswscale）
- 第15节：音频重采样
- 第16节：音视频剪辑与拼接

### 模块四：音视频视频播放与同步
- 第17节：SDL2渲染基础
- 第18节：音频播放与回调机制
- 第19节：视频播放循环
- 第20节：音视频同步原理
- 第21节：播放控制功能

### 模块五：网络流媒体与实时通信
- 第22节：RTMP推流与拉流
- 第23节：HLS流媒体生成
- 第24节：WebRTC基础架构
- 第25节：实时音视频采集
- 第26节：项目实战：简易直播系统

## 学习建议
1. 按顺序学习，每节课完成后再进入下一节
2. 动手运行所有代码实验，观察输出结果
3. 完成课后小挑战，巩固所学知识
4. 遇到问题先查看代码注释和讲义说明

## 技术栈
- **基础实验篇**：Python + OpenCV + NumPy + Matplotlib + Jupyter
- **工程实战篇**：C++17 + FFmpeg API + SDL2 + CMake
