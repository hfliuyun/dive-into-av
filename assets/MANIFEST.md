# 测试素材清单

本文档记录《动手学音视频开发》课程使用的轻量测试素材。新增素材时必须记录来源、生成命令或许可证信息，避免引入不可追踪或不适合提交的大文件。

---

## 素材规范

### 视频素材

- 时长：5-10 秒
- 分辨率：360p 或 720p
- 编码：H.264 为主，必要时补充 H.265
- 容器：MP4 为主，必要时补充 MKV、FLV、TS
- 码率：500-1500 kbps
- 实验运行目标：小于 3 秒

### 音频素材

- 时长：5-10 秒
- 采样率：44.1kHz 或 48kHz
- 声道：单声道或立体声
- 格式：WAV、AAC

### 图片素材

- 分辨率：720p 左右
- 格式：JPG 或 PNG

## 推荐生成命令模板

> 下面命令仅作为模板，实际使用前请根据课程章节调整文件名和参数。

### 生成 5 秒测试视频

```bash
ffmpeg -f lavfi -i testsrc=size=640x360:rate=30 -f lavfi -i sine=frequency=1000:sample_rate=48000 -t 5 -c:v libx264 -pix_fmt yuv420p -c:a aac assets/video/test_360p_5s.mp4
```

### 生成 5 秒 WAV 测试音频

```bash
ffmpeg -f lavfi -i sine=frequency=440:sample_rate=48000 -t 5 -c:a pcm_s16le assets/audio/test_48k_s16le_5s.wav
```

### 从 MP4 导出 H.264 裸流

```bash
ffmpeg -i assets/video/test_360p_5s.mp4 -c:v copy -an -bsf:v h264_mp4toannexb assets/video/test_360p_5s.h264
```
